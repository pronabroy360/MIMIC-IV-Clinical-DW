# Data Directory

This directory is intentionally ignored by git.

Place the openly accessible MIMIC-IV demo files under:

```text
data/raw/mimic-iv-demo/2.2/hosp/
data/raw/mimic-iv-demo/2.2/icu/
```

Credentialed full MIMIC-IV users can place local files under:

```text
data/raw/mimic-iv/3.1/hosp/
data/raw/mimic-iv/3.1/icu/
```

Do not commit MIMIC-IV data, DuckDB databases, patient-level exports, or
screenshots containing patient-level records.
